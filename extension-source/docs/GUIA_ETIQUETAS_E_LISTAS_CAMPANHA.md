# Guia rápido — Etiquetas do WhatsApp e listas de campanha

## 1. Sincronizar etiquetas

1. Abra o WhatsApp Web e confirme que as conversas terminaram de carregar.
2. No i9Hub, abra **CRM** e clique em **Sincronizar etiquetas**.
3. A extensão lê as etiquetas que o WhatsApp Web disponibiliza e associa os nomes às tags dos contatos no CRM.
4. Confira a mensagem de resultado. Ela informa quantas etiquetas foram lidas, quantos contatos tinham etiquetas e quantos registros foram criados ou atualizados.

As etiquetas existem normalmente no WhatsApp Business. Se o WhatsApp não expuser uma coleção de etiquetas, use **Diagnóstico de etiquetas**; a extensão não inventará etiquetas nem contatos.

## 2. Criar uma lista reutilizável

1. No CRM, clique em **Campanha WhatsApp**.
2. Escolha **Por nível ou etiqueta**.
3. Abra **Filtrar por etiqueta** e selecione uma ou mais etiquetas. Não é obrigatório escolher um estágio do funil.
4. Confira a quantidade de contatos elegíveis no resumo.
5. Em **Listas de campanha salvas**, digite um nome — por exemplo, `Clientes VIP` — e clique em **Salvar filtros**.

A lista salva guarda os critérios de estágio, etiqueta e grupo, não uma cópia congelada dos contatos. Ao carregá-la numa campanha futura, o i9Hub recalcula a prévia com os dados atuais do CRM.

## 3. Enviar uma campanha para a lista

1. Abra **Campanha WhatsApp**.
2. Em **Listas de campanha salvas**, selecione a lista e clique em **Carregar**.
3. Confira a quantidade e os contatos da prévia.
4. Escreva a mensagem e escolha **Criar (rascunho)** ou **Criar e iniciar** quando estiver pronto para enviar.

Sincronizar ou carregar uma lista não envia mensagens. O envio só começa quando o usuário inicia a campanha explicitamente.

## Regras importantes

- A etiqueta vira uma tag do CRM; não altera o estágio comercial do contato.
- Contatos duplicados são consolidados na lista da campanha.
- A Black List sempre é excluída.
- Contatos classificados como Spam ficam fora por padrão; só entram se o usuário marcar a opção correspondente.
- Use campanhas apenas para contatos que tenham consentido em receber comunicações e respeite pedidos de descadastro.
- A leitura depende das estruturas internas disponibilizadas pelo WhatsApp Web, que podem mudar. Se o número de contatos estiver zerado ou inesperado, execute o diagnóstico antes de iniciar uma campanha.
